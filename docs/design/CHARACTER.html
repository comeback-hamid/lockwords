Lockwords character spec

One character, two forms. Pixel Sprout for chat. Sound bars with eyes for voice calls. This file holds the design, every state, the change between forms, and a working reference renderer. Version 1.1 adds 34 animations: celebrations, work, feelings, touch and moments.

Theme
For an AI agent or developer: read the JSON block #character-spec first. It is the single source of truth. Then port the function createCharacter() at the bottom of this file. Do not copy numbers from the prose; take them from the JSON.

1. Overview

Chat form: Pixel Sprout

A green pixel block with two eyes, two small arms, two feet and a seedling leaf on top. It shows feelings with its body: arms, leaves, eyes and a small mouth.

Used in the Sprout tab: home greeting, Make a deck, and Talk (text chat).

Call form: Sound bars with eyes

The body splits into seven bars. The two eyes stay. The bars show sound: low and soft when it listens, tall and strong when it speaks.

Used when the user starts a voice call. When the call ends, the bars join back into Sprout.

One rule for all states: listening is calm and motion flows in. Speaking is strong and motion flows out.

3. Colors

Two palettes with the same token names. Light uses the Lockwords greens (GitHub Primer light). Dark uses GitHub's dark greens. No gradients on the character.

4. Shape and parts

The character sits on a grid. The body is always drawn as 7 slabs, each 2 units wide. In chat form the slabs touch, so they look like one block. In call form each slab gets thinner and becomes a bar. This is why the change between forms is smooth.

5. Chat form states

Each card is live. "When" tells you the moment in the app. One-shot states list how long to hold them before going back. States are in groups. A state with a timeline is a short planned move; on this page it plays again after a short rest.

7. Changing form: chat to call and back

The change takes ms. It has three overlapping steps. Going back to chat plays the same steps in reverse.

10. Build notes

TopicNote
iOS drawingUse SwiftUI TimelineView(.animation) with Canvas. Draw plain rectangles from the JSON numbers. Turn off antialiasing so pixels stay sharp.
SizeThe view box is 28 by 20 units. Pick a whole number of points per unit (for example 6 pt per unit = 168 by 120 pt). Smallest good size: 3 pt per unit.
Voice level, listeningTap the mic with AVAudioEngine. Level = min(1, RMS × 6). Pass it to the character every frame.
Voice level, speakingTap the audio player that plays Sprout's voice, same formula. In text chat with no audio, use the fake voice from the reference renderer while text is streaming.
Per-bar levelsSimple way: one level × the bar shape × a little random jitter (this is what the demo does). Better way: 4 frequency bands, low sounds in the middle bar, high sounds at the edges.
Reduce MotionStop all loops. Keep the poses, the eye changes and the bar heights. Replace the form change with a 200 ms cross-fade.
Brand feelCalm, flat, precise. Party effects (rising squares, falling squares, the pixel tree, the level square) use only the 5 word-level greens. No colored confetti, no gradients, no outlines.
Changing the shapeAll shape numbers are in geometry in the JSON. You can change the leaf, feet or arms there without touching any state.

11. How to build it on each platform

The plan is the same everywhere. Only the drawing and audio calls change. API names below were correct when this was written; check the current docs of each library before you use them.

11.1 Same on every platform

StepWhat to do
1. Ship the specCopy the JSON from #character-spec into the app as a file (for example character-spec.json). Load it once at start. Never type the numbers into code.
2. Make a modelOne plain object that holds: form, state, m (form change, 0 to 1), P (the current pose numbers), bars[7], barColor[7], lvl, and the blink timers. It is not UI state. Changing it must not rebuild the screen.
3. Port step(t, dt)Copy the numbered steps (0 to 11) inside createCharacter() in this file, in the same order. At the end, the model gives a list of rectangles: x, y, width, height, color, opacity.
4. DrawOnce per screen frame: call step, then draw the rectangles in this order: shadow, effects, leaf and stem, feet, arms, 7 slabs, highlight row, shade row, cheeks, eyes, mouth, and last the scan line. The body group (everything except shadow and effects) gets one transform: move, rotate around the pivot, scale from the pivot, then spin around the body center.
5. Keep pixels sharpUse a whole number of screen points per unit. Turn antialiasing off. The view box is 28 by 20 units and starts at x −5, y −6, so shift the drawing by 5 and 6 units.
6. EffectsThe small effects (sound pixels, dots, zzz, sparkles, squares, ? ! ×) are simple loops. Their positions are in the markup() function and their timing is in the CSS @keyframes at the top of this file. Port each one as a few lines of math on time. Effects in syncedEffects play once per cycle: start them when the timeline or the loop motion starts.
7. Public APIGive the rest of the app five calls: setState(form, state), setLevel(0…1), setProgress(0…1) (for making and timer), setLook(x, y) (for curious) and setTheme(light | dark). The chat and call code call these when events happen (see section 8).
8. Voice levelListening: level from the microphone. Speaking: level from the audio that is playing. Level = min(1, RMS × 6) for raw samples. If you only get decibels, use level = clamp((dB + 50) / 50, 0, 1). With no audio, use the fake voice rule.
9. Reduce MotionIf the user turned on Reduce Motion: stop the loops, keep poses and bar heights, and cross-fade the form change in 200 ms.
10. CheckOpen this page next to your build. Put both in the same state and compare. They should look the same.

The code samples below are short on purpose. They show the frame loop and the drawing call. They leave out the body transform from step 4: wrap the body rectangles in save, move, rotate, scale, restore.

11.2 Native iOS (SwiftUI)

TopicUse
DrawingCanvas inside TimelineView(.animation). Draw with Core Graphics through withCGContext so you can turn antialiasing off.
SpecDecode the JSON with Codable structs.
Mic levelAVAudioEngine: install a tap on inputNode, compute RMS of each buffer.
Voice levelInstall a tap on the player node or on mainMixerNode. With AVAudioPlayer, turn on isMeteringEnabled and read averagePower (decibels).
Reduce Motion@Environment(\.accessibilityReduceMotion)
struct CharacterView: View {
  let model: CharacterModel                      // plain class, holds the spec and the state
  @Environment(\.accessibilityReduceMotion) var reduceMotion

  var body: some View {
    TimelineView(.animation(paused: reduceMotion)) { timeline in
      Canvas { ctx, size in
        let u = floor(size.width / 28)           // whole points per unit
        model.step(now: timeline.date)           // the 11 steps of createCharacter()
        ctx.withCGContext { cg in
          cg.setShouldAntialias(false)
          cg.translateBy(x: 5 * u, y: 6 * u)     // view box starts at -5, -6
          for r in model.rects {                 // already in draw order
            cg.setFillColor(r.cgColor)
            cg.fill(r.frame(unit: u))
          }
        }
      }
    }
    .aspectRatio(28.0 / 20.0, contentMode: .fit)
  }
}

11.3 Native Android (Jetpack Compose)

TopicUse
DrawingCompose Canvas. Drive frames with withFrameNanos. Draw through drawIntoCanvas with a Paint that has isAntiAlias = false.
SpecPut the JSON in assets and decode it with kotlinx.serialization.
Mic levelAudioRecord: read PCM samples and compute RMS. Needs the RECORD_AUDIO permission.
Voice levelIf you play PCM yourself (AudioTrack), compute RMS on the samples you write. With ExoPlayer / Media3, add an audio processor that reads the samples. The Visualizer class also works but needs the record permission.
Reduce MotionRead Settings.Global.ANIMATOR_DURATION_SCALE. A value of 0 means animations are off.
@Composable
fun CharacterView(model: CharacterModel, modifier: Modifier = Modifier) {
  var frameMs by remember { mutableLongStateOf(0L) }
  LaunchedEffect(Unit) { while (true) withFrameNanos { frameMs = it / 1_000_000 } }
  val paint = remember { Paint().apply { isAntiAlias = false } }

  Canvas(modifier.aspectRatio(28f / 20f)) {
    val u = floor(size.width / 28f)              // whole pixels per unit
    model.step(frameMs.toDouble())               // reading frameMs here redraws every frame
    drawIntoCanvas { canvas ->
      canvas.translate(5 * u, 6 * u)
      for (r in model.rects) {
        paint.color = r.color
        canvas.drawRect(r.toRect(u), paint)
      }
    }
  }
}

11.4 Flutter

TopicUse
DrawingCustomPaint with a CustomPainter. Drive it with a Ticker and pass a Listenable as repaint, so only the painter redraws (no setState per frame). Use Paint()..isAntiAlias = false.
SpecAdd the JSON to assets in pubspec.yaml, load it with rootBundle.loadString and jsonDecode.
Mic levelThe record package gives the amplitude in decibels (onAmplitudeChanged). Convert with the decibel formula in 11.1.
Voice levelMost player packages do not give a level. If the voice arrives as PCM chunks, compute RMS on the chunks you play. If not, use the fake voice while audio is playing.
Reduce MotionMediaQuery.of(context).disableAnimations
NoteOne Flutter build covers iOS and Android. Nothing in the character needs platform code except audio.
class CharacterPainter extends CustomPainter {
  CharacterPainter(this.model, Listenable tick) : super(repaint: tick);
  final CharacterModel model;
  final Paint _paint = Paint()..isAntiAlias = false;

  @override
  void paint(Canvas canvas, Size size) {
    final u = (size.width / 28).floorToDouble();  // whole pixels per unit
    canvas.translate(5 * u, 6 * u);
    for (final r in model.rects) {
      _paint.color = r.color;
      canvas.drawRect(r.toRect(u), _paint);
    }
  }

  @override
  bool shouldRepaint(CharacterPainter old) => false;
}

11.5 React Native

TopicUse
Drawing@shopify/react-native-skia with react-native-reanimated. Build one Skia Picture per frame on the UI thread. Do not use React state per frame, and do not use react-native-svg for this: both are too slow for many moving parts.
Specimport spec from './character-spec.json'
Step functionWrite stepCharacter() as a worklet (a pure function with 'worklet' at the top) so it can run on the UI thread. Keep form, state and level in shared values.
Mic levelExpo audio recording with metering turned on gives decibels. Convert with the decibel formula in 11.1.
Voice levelPlayback metering is usually not available. If the voice arrives as PCM chunks, compute RMS on them. If not, use the fake voice while audio is playing.
Reduce MotionuseReducedMotion() from Reanimated, or AccessibilityInfo.isReduceMotionEnabled().
import { Canvas, Picture, Skia, createPicture, useClock } from '@shopify/react-native-skia';
import { useDerivedValue, useSharedValue } from 'react-native-reanimated';
import spec from './character-spec.json';

export function CharacterView({ width }) {
  const u = Math.floor(width / 28);              // whole points per unit
  const clock = useClock();                      // time in ms, runs on the UI thread
  const input = useSharedValue({ form: 'chat', state: 'idle', level: 0 });
  const memory = useSharedValue(newCharacterMemory(spec));   // m, pose, bars, blink timers

  const picture = useDerivedValue(() => {
    'worklet';
    const rects = stepCharacter(spec, memory, input.value, clock.value);  // port of step()
    return createPicture((canvas) => {
      const paint = Skia.Paint();
      paint.setAntiAlias(false);
      canvas.translate(5 * u, 6 * u);
      for (const r of rects) {
        paint.setColor(Skia.Color(r.color));
        canvas.drawRect(Skia.XYWHRect(r.x * u, r.y * u, r.w * u, r.h * u), paint);
      }
    });
  });

  return (
    <Canvas style={{ width: 28 * u, height: 20 * u }}>
      <Picture picture={picture} />
    </Canvas>
  );
}
